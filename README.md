EMBERFALL — hold the last ember through ten nights. Pilot your ember ship around the burning Ember Heart at the arena's core: Kindlers and the Ember Tyrant hunt the Heart itself, and if it falls the night wins. Dodge and shoot through 10 named nights of geometric hunters — including dark nights where only the Heart's light reveals the Shades — dash through danger, pick upgrades between nights (including ones that arm the Heart itself), and defeat the Ember Tyrant.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or serve game/ with any static HTTP server.
